# Data Structures Lab

A collection of lab assignments and practical implementations for the **Data Structures** course in the BS Data Science program at **Air University, Islamabad, Pakistan**. All assignments are implemented in **C++** as part of my university coursework.

## About

This repository contains programming tasks completed during Data Structures lab sessions. It covers fundamental data structures, array manipulation, searching techniques, and practical applications of linked lists.

Each lab is organized into a separate directory, with individual C++ source files for each task.

## Labs and Topics

| Lab    | Topic                             | Description                                                                                                                            |
| ------ | --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Lab 02 | Arrays                            | Array input/output, insertion, deletion, searching, updating, multidimensional arrays, and dynamic arrays.                             |
| Lab 03 | Arrays and Practical Applications | Student marks management, parking management, matrix output, hospital bed management, computer lab management, and 3D array searching. |
| Lab 04 | Linked Lists                      | Singly linked list applications, including student registration, hospital patient queues, and online shopping cart management.         |

## Concepts Practiced

* **Arrays:** Traversal, insertion, deletion, searching, and updating.
* **Multidimensional Arrays:** Working with 2D and 3D arrays.
* **Searching Algorithms:** Finding elements in arrays.
* **Linked Lists:** Implementing dynamic nodes and linked list operations.
* **Practical Applications:** Applying data structures to student records, hospital management, and shopping cart systems.
* **C++ Programming:** Problem-solving, functions, pointers, and memory management where applicable.

## How to Compile and Run

Each `.cpp` file contains a separate C++ program that can be compiled and executed independently.

### Prerequisites

* A C++ compiler, such as **G++**.
* Visual Studio Code or another C++ development environment.

### Compile and Run on Windows (PowerShell)

For example, to compile and run a task from Lab 02:

```powershell
g++ Lab_02_array/Task_01.cpp -o task01.exe
.\task01.exe
```

To compile and run a Lab 03 task:

```powershell
g++ Lab_03/Task1_StudentMarks.cpp -o task.exe
.\task.exe
```

To compile and run a Lab 04 task:

```powershell
g++ Lab_04_LinkList/Task1_Student_Registration.cpp -o task.exe
.\task.exe
```

**Note:** Replace the source filename with the task you want to execute. Make sure G++ is installed and available in your system's PATH.
