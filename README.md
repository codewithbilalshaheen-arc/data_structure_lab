# Data Structures Lab

Lab work for the **Data Structures** course, part of the BS Data Science program at **Air University, Pakistan**. This repo holds the code I write and submit during lab sessions.

## About

Each lab is organized in its own folder, containing the tasks assigned for that session. All code is written in **C++**.

## Structure
data_structure_lab/
└── Lab_02_array/
├── Task_01.cpp
├── Task_02.1.cpp
├── Task_03.1.cpp
├── ...


- Folders are named `Lab_XX_<topic>` (e.g. `Lab_02_array`).
- Each file is a standalone task (`Task_XX.cpp`) that can be compiled and run independently.

## Labs

| Lab | Topic | Description |
|-----|-------|-------------|
| Lab 02 | Arrays | Array input/output, insertion, deletion, searching, updating, 2D/3D arrays, dynamic arrays |

*(This table will grow as new labs are added.)*

## How to Compile & Run

Each task is a single-file C++ program. Compile with g++ (or any C++ compiler):

```bash
g++ Lab_02_array/Task_01.cpp -o task01
./task01
```
